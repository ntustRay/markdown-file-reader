# Ray Markdown Reader — Release Notes

## 1.0.0

First Android release candidate.

- Open one local `.md`, `.markdown`, or `.txt` file
- Preview Markdown or read unformatted plain text
- Switch between full-screen Preview and Edit
- Save changes back to the selected file
- Confirm Save, Discard, or Cancel before leaving changed work
- Preserve UTF-8 BOM and LF/CRLF line endings
- Support light/dark themes, English, and Traditional Chinese
- Open only HTTP(S) links in the external browser
- No accounts, ads, tracking, cloud sync, or broad storage access

Google Play What's new:

`First release: open, preview, edit, and save local Markdown and text files.`
